🤖 Powered By Semantic Search

This isn't a keyword bot.

It's using:

SentenceTransformer('all-MiniLM-L6-v2')

Which means it actually compares:

meanings

instead of

exact words

For example:

Tell me about Cortex

and

Who is Neo Cortex?

can both reach the same answer.

Fancy.
